# ClusterAudienceKit Roadmap

**Current Version:** v2.0.0

## Vision

ClusterAudienceKit provides customer segmentation through RFM analysis, clustering, and streaming updates for martech pipelines.

## Completed Milestones

✅ **v1.0-1.5** — Core Foundation
- RFM (Recency, Frequency, Monetary) analysis
- Clustering algorithms (K-Means, DBSCAN, Hierarchical)
- Streaming update support
- Segment materialization

✅ **v2.0 (July 2026)** — Workflow Integration
- CLI: `clusteraudiencekit create-audience`, `refresh-audience`, `get-members`, `create-segment`
- REST API (Port 8002) for automation
- n8n, Power Automate, Airflow integration
- Audience management & metrics

## In Progress

⏳ **v2.1 (Aug 2026)** — Advanced Analytics
- Predictive segmentation
- Churn risk scoring
- Lifetime value (LTV) prediction
- Cohort analysis

## Planned

📅 **v2.5 (Sep 2026)** — Real-time Activation
- Streaming segment updates
- Event-based triggers

- Webhook integrations

📅 **v3.0 (Oct 2026)** — ML Pipeline Integration
- Scikit-learn pipelines

📅 **v3.5 (Q4 2026)** — Enterprise Features
- Multi-tenant support

📅 **v4.0 (Q1 2027)** — Full Stack

## Integration Points

- **Data Platforms:** Snowflake, BigQuery, Redshift, PostgreSQL
- **Workflow Tools:** n8n, Power Automate, Temporal, Airflow
- **Activation:** PyCustomerJourney, PyReverseETL
- **Analytics:** Tableau, Looker, Metabase
